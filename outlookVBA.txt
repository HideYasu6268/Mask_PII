Sub RunMaskPII()

　使い方（Outlookへの登録方法）
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

このマクロは、Outlookの画面から1クリックで
「Mask_PII.exe」を起動できるようにするためのものです。

【① マクロを登録する】

1. Outlookを開き、キーボードで「Alt」+「F11」を押して
   VBAエディタ（Microsoft Visual Basic for Applications）を開きます。
2. 左側の「プロジェクト」欄で「Project1」を右クリックし、
   「挿入」→「標準モジュール」を選びます。
3. 追加されたモジュール（Module1など）の右側の白い画面に、
   上記の
       Sub RunMaskPII()
           Shell "Your-exe-Adress-Here", vbNormalFocus
       End Sub
   をそのままコピー＆貼り付けします。
4. 「Your-exe-Adress-Here」の部分を、実際の
   「Mask_PII.exe」の場所（フルパス）に書き換えます。
   　例：Shell "C:\MyPython\Mask_PII\Mask_PII.exe", vbNormalFocus
   ※ パスの前後の　「" "」（ダブルクォーテーション）は消さないでください。
5. 画面左上の保存アイコン（フロッピーのマーク）を押して保存します。
   保存時に「マクロを無効にして保存しますか」等の確認が出た場合は、
   ファイルの種類を「Outlook用マクロ有効ファイル(*.otm)」のまま保存してください。
6. VBAエディタを閉じてOutlookの画面に戻ります。

【② マクロのセキュリティ設定を確認する】

初めてマクロを使う場合、Outlookがマクロをブロックすることがあります。
「ファイル」→「オプション」→「トラストセンター」→
「トラストセンターの設定」→「マクロの設定」を開き、
「警告を表示してすべてのマクロを無効にする」に　なっていることを確認してください
（実行時に警告ダイアログが出るので、その都度「有効にする」を選べば動作します）。

【③ ボタンとして登録する（クイックアクセスツールバー）】

毎回メニューから探すのは手間なので、ワンクリックのボタンにしておくと便利です。

1. Outlook画面左上の「≡」（またはタイトルバー）を右クリックし、
   「クイックアクセスツールバーのユーザー設定」を選びます。
2. 「コマンドの選択」を「マクロ」に変更すると、
   一覧に「RunMaskPII」が表示されるので選択し、「追加」ボタンを押します。
3. 「変更」ボタンから、わかりやすいアイコンと名前
   （例：「PII匿名化ツール起動」）に変更できます。
4. 「OK」を押すと、Outlook画面上部に常にボタンが表示されるようになります。

【④ 使うとき】

登録したボタンを1回クリックするだけで、「Mask_PII.exe」が起動します。
起動後の操作方法は「使い方.txt」を参照してください。

【うまく動かないときは】

・ボタンを押しても何も起きない
　→ 手順①-4で書き換えたパスが正しいか（フォルダ名やファイル名に
　　誤りがないか）確認してください。
・「マクロが無効にされました」という警告が出て止まる
　→ 警告ダイアログで「マクロを有効にする」を選んでください。
・そもそもボタンやマクロの一覧に「RunMaskPII」が出てこない
　→ 手順①で保存がうまくいっていない可能性があります。もう一度
　　Alt+F11でVBAエディタを開き、コードが残っているか確認してください。
