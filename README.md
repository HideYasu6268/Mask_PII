# Mask_PII

PII 匿名化デスクトップアプリです。社内の Outlook/メール本文を入力として扱い、
個人情報を自動検出して匿名化した後、返信文の案まで生成できるツールです。

このリポジトリでは、運用上のメインエントリとして [main_all_in_without_api.py](main_all_in_without_api.py) を使います。
実行時はこのファイルをそのまま起動してください。

## 主要な特徴

- メール本文や手入力テキストから PII を検出
- 氏名・会社名・住所・メールアドレス・電話番号・郵便番号などに対応
- ローカル GGUF モデルを使って、辞書だけでは拾い切れない情報も検出
- 対応表を編集して、置換結果をプレビューできる
- 匿名化後の文章をもとに返信案を生成
- Outlook の返信作成画面に直接差し込める
- 初回のモデル取得を除き、ローカル完結を目指す構成

## 実行方法

### 1. 依存関係を入れる

```bash
pip install -r requirements.txt
```

Windows では `llama-cpp-python` のプレビルド wheel が使えるため、通常は比較的スムーズに導入できます。
必要に応じて、NER の精度向上のために次も追加します。

```bash
pip install spacy ginza ja-ginza
```

### 2. メインファイルを起動

```bash
python main_all_in_without_api.py
```

このファイルは、外部ファイルからの秘密情報を埋め込みせずにコミットできるようにした
サンプル版です。実運用でキーや署名を埋め込む場合は別途ローカル用のファイルを使う前提です。

## モデルについて

初回起動時に、アプリ側で `models/` フォルダ配下に GGUF モデルが無ければ自動ダウンロードを試みます。
標準では `Qwen2.5-7B-Instruct-Q4_K_M.gguf` を想定しており、
モデルがすでにある場合はネットワークアクセスを避けてローカルで利用します。

この運用の利点は、 `models/` フォルダごとコピーすれば別 PC でも同じモデルを使える点です。

## 使い方の流れ

1. アプリ起動
2. 上部の「モデル準備」を実行してモデルが揃うことを確認
3. Outlook からメールを取得するか、原文欄に本文を入力
4. 「匿名化対象を検出」を実行
5. 対応表で検出結果を確認・修正
6. 「プレビュー更新」で匿名化後の本文を確認
7. 必要に応じて返信の方針を入力して AI 返信案を生成
8. 内容を確認し、Outlook の返信作成画面で仕上げる

## 重要な注意点

- 署名や API キーを使う場合は、実環境に合わせてローカル設定を用意してください
- 匿名化前の本文や辞書には実際の顧客情報が含まれるため、画面共有や共有フォルダには注意してください
- 生成された返信案はあくまで草案です。最終送信前に必ず内容を確認してください
- このアプリは OpenAI ではなくローカル LLM と Gemini を組み合わせているため、実行環境やネットワーク条件に依存します

## 主な前提条件

- Windows を想定
- Python 3.10 以降を推奨
- Outlook Desktop が利用可能な環境でメール取得を使う
- ローカル LLM を使う場合は `models/` 配下に GGUF ファイルが必要

## 開発メモ

このプロジェクトは、実用性を優先して「ローカルでの匿名化 → 確認 → 返信案生成 → Outlook 返信作成」の流れを一つのアプリとしてまとめたものです。
特に [main_all_in_without_api.py](main_all_in_without_api.py) は、現状のメイン起動ファイルとして機能させるために、
リポジトリで共有しやすい構成に整理されています。
